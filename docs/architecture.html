2. Who may call what

Two tokens. The parent token is short-lived and comes only from the PIN.

Email + passwordPOST /auth/login (8 tries, then escalating lock)
Family token, 30 daysLessons, quizzes, puzzles, Hoot, usage, reports
Parent PINPOST /auth/parent-unlock (5 tries, then lock)
Parent token, 10 minutes/parent/*: profiles, sensitive topics, chats, export
Password againDelete account · change password. Every token carries a session version; raising it signs out all devices.

3. The hint ladder

Invariant: an answer leaves the server only after a correct try or all three hints, in order.

Lesson is sent without answerspublicLesson() strips answer, hints, explain; options shuffled per child
Child triesPOST …/check → correct or not, nothing else
Hint 1 → 2 → 3POST …/hint; skipping is refused; level saved in hints_seen
Reveal checkmayReveal() reads hints_seen, not the app's claim
Explanation, then review date…/complete scores first tries; spaced repetition

4. Hoot: what happens to one message

Red steps can stop the message or replace the reply with the lesson's own pre-written hint. Steps 2, 6 and 8 use no AI.

GatesLesson visible · age 6+ · Hoot switched on by the parent · 500 characters at most
Built-in checks (no AI)Personal information → removed, fixed reply. Self-harm or abuse (read across the last 3 messages) → kind fixed reply with a helpline, email to the parent without the child's words.
Daily limit40 messages per child, counted atomically
Model writes a draftSystem instructions for the age band + lesson context (including the secret answer and whether the question is solved) + the last 12 turns
Own models only: rule reminderKey rules and worked examples placed last; private <think> text removed
Fixed checks (no AI)No links · length limit by age · must not name only the correct option
Second model call judges the draft{ safe_for_age, reveals_answer }
Fail closedUnsafe, leaking, unreadable verdict, timeout or error → pre-written hint, message flagged for the parent
Child sees the replyParent can read every chat with the PIN
